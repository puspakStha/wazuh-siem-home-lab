# Wazuh SIEM Home Lab — Windows 11 Monitoring

## 1. Project Overview

This project demonstrates the deployment of a Wazuh Security Information and Event Management (SIEM) home lab to monitor a Windows 11 endpoint, review security events, and investigate alerts.

The lab was created to develop practical skills in security monitoring, endpoint visibility, log analysis, and incident investigation.

## 2. Objectives

- Deploy a Wazuh server and dashboard in a virtualized environment.
- Connect a Windows 11 endpoint using the Wazuh agent.
- Verify endpoint connectivity and event collection.
- Investigate security alerts and relevant log entries.
- Document findings and recommend defensive actions.

## 3. Lab Architecture

- **Host operating system:** Windows 11
- **Virtualization platform:** VirtualBox
- **SIEM platform:** Wazuh
- **Monitored endpoint:** Windows 11
- **Server components:** Wazuh manager, indexer, and dashboard

## 4. Implementation

1. Set up the Wazuh virtual machine.
2. Accessed the Wazuh dashboard.
3. Installed and configured the Windows agent.
4. Started the Wazuh agent service.
5. Checked the endpoint connection in the dashboard.
6. Prepared the environment for security event investigation.
